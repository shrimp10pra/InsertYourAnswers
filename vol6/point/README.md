# 得点表（4チーム対抗戦）

企画ごとのルールに沿って得点を自動集計する、ブラウザだけで動く静的サイトです。

## ルール

| 企画 | 集計方法 | 回数 |
|---|---|---|
| 企画1 | 獲得点がそのまま持ち点 | 2回 |
| 企画2 | 順位ポイント（1位25pt / 2位20pt / 3位15pt / 4位10pt） | 2回 |
| 企画3 | 順位ポイント（1位25pt / 2位20pt / 3位15pt / 4位10pt） | 1回 |
| 企画4 | 順位ポイント（1位25pt / 2位20pt / 3位15pt / 4位10pt） | 2回 |
| 企画5 | 獲得点がそのまま持ち点 | 1回 |

順位ポイント方式で同点が出た場合は、該当する順位の点数を平均して同点チーム全員に割り当てます
（例：1位が2チーム同点なら 25pt と 20pt の平均 22.5pt を両チームに付与）。

## ファイル構成

```
index.html   … ページ構造
style.css    … デザイン
script.js    … 集計ロジック・保存処理
```

外部依存は Google Fonts（Bebas Neue / Noto Sans JP）のみで、それ以外は完全に自己完結しています。

## GitHub Pages での公開方法

1. このフォルダの中身（`index.html` / `style.css` / `script.js`）を GitHub リポジトリの直下に置く
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、ブランチを `main`（フォルダは `/root`）に設定して保存
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でサイトが公開されます

## 使い方

- 「チーム名」欄でチーム名を編集できます
- 各企画の「得点入力」欄に、各チームの獲得点を入力すると自動で持ち点・順位ポイントが計算されます
- 画面上部の「総合順位」「得点比較」がリアルタイムで更新されます
- ページ下部の「得点表（内訳）」に全企画・全回の内訳と合計が表示されます
- 入力内容はブラウザの localStorage に自動保存されます（この端末・このブラウザのみ。サーバーには送信されません）
- 「記録をリセット」ボタンで全データを初期化できます

## 注意点

- データはブラウザごとに保存されるため、別の端末や別のブラウザで開くと入力内容は共有されません。複数人・複数端末で同じ得点表を共有したい場合は、入力担当の端末を1台に決めて運用してください。
